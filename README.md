# Roopakjeet Kaur – Portfolio

A personal portfolio showcasing my projects, research, technical skills, certifications, achievements, and academic journey in **Software Development, Machine Learning, Computer Vision, and AI**.

## 🌐 Live Website

> *[Portfolio](https://roopakjeetkaur.vercel.app/)

## 👋 About

This portfolio brings together my work in AI, Machine Learning, Deep Learning, Computer Vision, and Full-Stack Development. It features detailed project case studies, professional experience, education, technical skills, certifications, and achievements.

## ✨ Features

* 🌸 Responsive portfolio with a custom aesthetic design
* 🌙 Dark & Light mode
* 📖 Interactive journal-style About section
* 💼 Detailed project pages with image galleries
* 🚀 Experience, Education, Skills & Certifications
* 📄 Resume download
* 📬 Contact section with social links

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Lucide Icons

## 🚀 Run Locally

```bash
git clone https://github.com/kaurroopak/My-Portfolio.git

cd My-Portfolio

npm install

npm run dev
```

## 📦 Build

```bash
npm run build
```
